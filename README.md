# Monitoreo de rodamientos: presentación del proyecto

Sitio de presentación del trabajo de investigación de Ingeniería de Software (UPC) *Sistema basado en IoT e Inteligencia Artificial para la detección temprana de fallas en rodamientos de maquinaria pesada en el Perú*.

Autores: Kevin Chi Cruzatt y Manuel Tumi Oliden.

- `index.html`: presentación del proyecto (el problema, cómo funciona, cómo identifica la parte que falla, quién lo usa y metas).
- `app.html`: prototipo navegable de la aplicación web, **con datos de ejemplo** (no son mediciones reales).
- `estilos.css` y `graficos.js`: estilos y gráficos compartidos.

Se publica con GitHub Pages desde la rama `main`. Para verlo en local:

```
python -m http.server 8765
```

y abrir `http://localhost:8765/`.
